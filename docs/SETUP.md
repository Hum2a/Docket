# Setup

Local and production setup for Docket (Worker name: `jobtracker`).

## Prerequisites

- Node.js 20+
- Cloudflare account + Wrangler login
- Neon Postgres database
- Optional: Resend account (digests + outreach)

## Install

```bash
npm install
cp .dev.vars.example .dev.vars
```

Edit `.dev.vars` with at least:

| Variable | Required | Purpose |
| --- | --- | --- |
| `DATABASE_URL` | Yes | Neon connection string |
| `API_KEY` | Yes | `X-Api-Key` for writes and outreach reads |
| `RESEND_API_KEY` | No | Email sending |
| `DIGEST_TO` / `DIGEST_FROM` | No | Job reminder digests |
| `OUTREACH_FROM` | No | Outreach From header |
| `OUTREACH_REPLY_TO` | No | Reply-To for outreach |
| `OUTREACH_POSTAL_ADDRESS` | No* | PECR footer (*required before real sends) |
| `RESEND_INBOUND_SECRET` | No | Inbound webhook auth (auto-generated by sync) |
| `UNSUBSCRIBE_SIGNING_KEY` | No | Signed unsubscribe tokens (auto-generated) |

`.dev.vars` is gitignored. Never commit real secrets.

## Database

```bash
npm run db:ping      # connectivity
npm run db:status    # applied vs pending
npm run db:migrate   # apply migrations/*.sql in order
```

Migrations:

| File | Purpose |
| --- | --- |
| `001_docket_schema.sql` | Job applications, notes, reminders, documents |
| `002_app_settings.sql` | App settings |
| `003_outreach_schema.sql` | Leads, messages, suppressions, outreach settings |
| `004_outreach_fixes.sql` | Outreach follow-up fixes |
| `005_allow_primary_domain.sql` | Sending-domain policy |
| `006_lead_drafts.sql` | Custom subject/body drafts |
| `007_message_attempts.sql` | Message attempt tracking |

If `001` was applied manually before `schema_migrations` existed:

```sql
CREATE TABLE IF NOT EXISTS schema_migrations (
  id TEXT PRIMARY KEY,
  applied_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
INSERT INTO schema_migrations (id) VALUES ('001_docket_schema.sql')
ON CONFLICT DO NOTHING;
```

### Secrets

```bash
npm run secrets:local      # write/generate into .dev.vars only
npm run secrets:sync       # .dev.vars → wrangler secret put
npm run secrets:dry-run    # preview sync
```

`secrets:sync` generates missing `RESEND_INBOUND_SECRET` and `UNSUBSCRIBE_SIGNING_KEY`, fills outreach/digest From defaults when empty, then pushes all known keys to Cloudflare.

Flags: `--force` (regenerate crypto keys), `--dry-run`, `--local`.

One-off prompts still work: `npm run secrets:db`, `secrets:key`, `secrets:resend`, etc.

After Resend is configured, use **Settings → Send test email** for job digests. Outreach uses `OUTREACH_FROM`, not the digest From.

## Local development

```bash
npm run dev
```

- SPA: [http://localhost:5173](http://localhost:5173) (proxies `/api` → Worker)
- Worker: [http://localhost:8787](http://localhost:8787)

```bash
npm run build:web
npx wrangler dev
```
